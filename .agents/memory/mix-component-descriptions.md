---
name: Mix component descriptions
description: Defines the authoritative source for public descriptions shown inside Mix component tables.
---

Public Mix component descriptions must use the Mix-specific copy supplied for that component row in the approved catalogue workbook. Do not substitute the linked product's general Blurb or Description.

**Why:** A component's role and wording can differ by Mix. The user explicitly rejected linked-product copy because it is not the approved component description.

**How to apply:** Preserve the workbook's Mix-component description through import, storage, admin editing, API output, and export. If source copy is blank, render no description rather than inventing a fallback.
