# IH Seeds — Product Fields for the Website Admin Portal

Field specification for the product/mix add-and-edit screen.

Every option list below is taken from the **IH Seeds Product Data (Master Catalogue)** — 150 product
records across 10 categories, plus the 2026 Pasture Growers Guide. Percentages show how many of the
150 records already hold data for that field, so you can judge what earns a place on the form.

Legend: **[BUILT]** already on the form · **[CHANGE]** exists but needs altering · **[NEW]** to add

### 4.2 Rainfall and soil

| Field | Type | Notes |
|---|---|---|
| `rainfall_min_mm` | integer **[CHANGE]** | Store the number, not "400+". Parses cleanly on 141/150 records, and a number lets customers filter by rainfall zone. |
| `soil_ph_min` | decimal **[NEW]** | **Missing entirely, 71% filled.** Distinct from soil *range* (which is texture). Legumes are sold on it — lucerne and sub clovers need 5.5 CaCl₂ minimum. |
| `soil_ph_scale` | select: `CaCl₂` \| `water` **[NEW]** | The tech sheets specify CaCl₂; without the scale the number is ambiguous. |
| `soil_range_lightest` | select **[BUILT]** | `LS` \| `S` \| `L` \| `H` |
| `soil_range_heaviest` | select **[BUILT]** | `LS` \| `S` \| `L` \| `H` |
| `sowing_depth_min_cm` / `sowing_depth_max_cm` | decimal **[NEW]** | 30% filled. |

Soil range key, for the form's help text: **LS** light sand · **S** sand · **L** loam · **H** heavy.

### 4.3 Tolerance — fix the option list

| Field | Type |
|---|---|
| `tolerance` | multi-select, each with a **Mild** qualifier **[CHANGE]** |

```
Low pH          ← MISSING from the current form
Waterlogging
Salinity        ← MISSING from the current form
Drought
Frost
```

The current chips are Drought / Frost / Waterlogging. **Low pH and Salinity are the two the printed
guide actually codes** — every guide row is tagged P (low pH), W (waterlogging) or S (salinity), and
that column pairs with Ideal Soil Range. Across the 150 records: waterlogging 71 mentions, low
pH/acid 59, salinity 46, drought 39, frost 25.

Salinity in particular is the headline claim for Puccinellia, Tall Wheat Grass, Reclaimer Rhodes
Grass and L97 Lucerne — in WA that is a category people search on.

The **Mild** qualifier is real data, not a nicety: the guide prints "Mild S" and "Mild P/W".

### 4.4 Maturity — split the single field into measure + value

The current single "Flowering / heading" text field is holding **four different measurements**, which
is why its placeholder has to read "Aug-Nov, Mid, or All Year R…". As one text field it cannot be
sorted or filtered, and lucerne data ends up mislabelled.

| Field | Type | Applies to |
|---|---|---|
| `maturity_measure` | single select **[CHANGE]** | see below |
| `maturity_days` | integer **[NEW]** | Clovers, serradellas — range in data 77–144 |
| `heading_date` | select **[NEW]** | Ryegrasses |
| `flowering_window` | text **[NEW]** | Mixes |
| `winter_activity` | integer 1–10 **[NEW]** | Lucerne only |

`maturity_measure` options:

```
Days to flowering (Perth)     → use maturity_days
Heading date                  → use heading_date
Time of flowering             → use flowering_window
Winter activity rating        → use winter_activity
```

`heading_date` options:

```
Very early
Early
Mid
Mid-late
Late
```

`flowering_window` observed values: `Aug-Nov`, `Aug-Oct`, `Jul-Aug`, `Summer`, `Winter`,
`All Year Round`.

> **Why this matters:** winter activity is a *dormancy* rating, not a flowering date. Storing L97's
> "9" in a field labelled flowering is simply wrong data.

## Priority order

If the whole list is too much for one build, this is the order that adds the most value per field:

1. **Fix the tolerance chips** — add Low pH and Salinity. Small change, and without it the form
   cannot record what the printed guide codes on every row.
2. **`end_use` multi-select** — 90% of products have it, it is how customers shop, and it is absent.
3. **Split the maturity field** — cheap to do now, painful to migrate after data entry starts.
4. **`sowing_rates` as repeatable rows** — same reasoning; 40+ products need it.
5. **`persistency_type`, `soil_ph_min`, `botanical_name`, `ploidy`** — high fill rates, all missing.
6. **`slug`** — before any product goes live and gets linked to.
7. Everything else.
